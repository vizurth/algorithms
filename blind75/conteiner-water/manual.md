### 11. Container With Most Water
```go
func maxArea(height []int) int {
    l, r := 0, len(height) - 1
    res := -1 
    for l < r {
        area := min(height[l], height[r]) * (r - l)
        res = max(res, area)
        if height[l] < height[r] {
            l++
        } else if height[r] < height[l] {
            r--
        } else {
            r--
            l++
        }
    }
    return res
}
```
### Описание алгоритма
Чистая задача на два указателя 
Возьмем поставим указатели на последние элементы и будем считать площадь которую можно заполнить водой, чтобы она была максимальной, возьмем минимальную по высоте стенку `min(height[l], height[r])` и количество стенок между ними + 1 `(r - l)` и будем двигать указатели если `h[l] < h[r]` будем двигать левую границу, чтобы найти стенку выше и аналогично `h[l] > h[r]` будем двигать правую, если  `h[l] == h[r]` то двигаем обе стенки

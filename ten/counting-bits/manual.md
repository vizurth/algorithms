### 338. Counting Bits

```go
func countBits(n int) []int {
    dp := make([]int, n + 1)
    for i := 0; i < n + 1; i++ {
        dp[i] = dp[i >> 1] + i % 2
    }

    return dp[:n + 1]
}
```

### Описание алгоритма

Используем ДП учитываем единицу четности и смотрим на предыдущие числа так как единица повторяются
